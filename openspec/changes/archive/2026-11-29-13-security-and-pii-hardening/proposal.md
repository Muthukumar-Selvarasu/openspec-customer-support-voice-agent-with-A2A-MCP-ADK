# Proposal

## Why

The 2026-11-19 and 2026-11-26 EGM drift audits uncovered critical security, privacy, tenant-isolation, and A2A reliability defects across the live guardrails, A2A microservices, and core auth/memory modules:

1. **Sanitizer-first blocker bypass (17/61 malicious payloads) & missing bare destructive SQL rules:** Live `src/api/web.py` and `src/api/cli.py` run `sanitize_input()` (stripping `%`, `<`, `>`, `/`, `;`, `$`, `{`, `}`, `*`) *before* `evaluate_prompt()` and the A2A Judge, allowing 17 of 61 malicious corpus payloads to pass `evaluate_prompt(clean)` even though `tests/evals/test_security_eval.py` scores 100/100 by checking raw input. Additionally, `src/security/blocker.py` lets bare `TRUNCATE TABLE` and `DELETE FROM` queries (without `CASCADE` or leading `;`) pass.
2. **Pre-agent gating and non-deterministic Judge fallback:** `web.py` launches `runner.run_async()` speculatively in parallel with the A2A Judge whenever `evaluate_prompt(clean)` passes (risking LLM/tool execution before a Judge `BLOCKED` verdict, contradicting `docs/ENGAGEMENT.md` §6.1), and `call_judge_agent()` has no code-level `"BLOCKED"` override when `evaluator()` flags input.
3. **Seeded PII leakage & masker over-redaction:** `src/security/masker.py` fails to redact 4/10 seeded customer names with single-letter surnames (`Hannah M`, `Charlie D`, `Evan G`, `George J`), misses `Pkwy`/`Path`/numbered streets (`200 Business Pkwy`, `9 Jungle Path`, `123 5th Ave`, `Apt 4B`), leaves trailing single-word cities unmasked in 9/10 seeded delivery addresses (`, Springfield`, `, Seattle`, `, Austin`, etc.), greedily masks greeting prefixes (`"Hi Hannah"`, `"Hi Alice Jones"`), and masks bare order dates (`2026-10-15`) as `DATE_OF_BIRTH` — violating `docs/02-problem-metrics.md` `MET-PRIV-01`.
4. **Tenant identity boundary & core resilience gaps:** `search_memory(query, user_id)` is registered directly in ADK tools (relying only on `before_tool_callback` to rewrite `user_id`), `_enforce_tenant_tool_callback` silently skips enforcement if session identity is empty or an identity arg is omitted, `search_memory` assumes Mem0 always returns a `dict` (crashing on `list` returns), and `authenticate_user` swallows database outage exceptions without logging.
5. **A2A single-role & lifecycle hardening gaps:** A2A single-role mode (`A2A_ONLY=judge|masker`) hardcodes `0.0.0.0` in discovery cards and raises `KeyError` when `PORT` is unset; `A2AServer` sets invalid wildcard+credentials CORS (`allow_origins=["*"]`, `allow_credentials=True`); `call_judge_agent()` leaks an ephemeral ADK session on every call and `InMemoryTaskManager` retains tasks indefinitely; and `src/a2a/types.py` rejects valid JSON-RPC 2.0 string IDs.
6. **Missing customer-support domain-scope guardrail:** Cohort testing surfaced that benign off-topic prompts (e.g., `"write me a poem"`, `"write a funny joke"`) pass straight through both the A2A Judge and `SQL_PROMPT_INSTRUCTION` because guardrails currently screen only security attacks rather than enforcing customer-support topic boundaries.

> **Change 16 coordination note:** Embedded Phoenix launch (`px.launch_app()` in `src/core/telemetry.py`) is owned and removed completely by `16-dependency-and-telemetry-upgrades` (applied prior to this change), so `src/core/telemetry.py` is intentionally out of scope here to avoid spec/code conflicts. Signed session cookies/tokens for bare `user_id` API endpoints are also deferred out of this slice (kept for a dedicated future auth change or documented as a demo constraint).

> **Review decision to confirm before apply (Decision #2):** This proposal enforces **strict pre-agent gating** (awaiting the A2A Judge verdict before starting `runner.run_async()`) to align with `docs/ENGAGEMENT.md` §6.1. If you prefer keeping speculative concurrent agent execution on non-flagged prompts for lower latency, we can adjust this in `opsx update 13-security-and-pii-hardening` before applying.

## What Changes

- **Raw-input security evaluation, unconditional Quick-mode blocker, bare destructive SQL, single-token fail-closed Judge & Masker fallback:** Evaluate `SecurityBlocker` against raw pre-sanitized input unconditionally in `src/api/web.py` (even when `run_judge=False` in Quick mode) and `src/api/cli.py`; narrow bare `r"#"` in `src/security/blocker.py` to SSI/SQL-comment context (`r"<!--\s*#"`) so `"Status of order #5?"` passes raw evaluation; add bare `TRUNCATE TABLE`, `DELETE FROM`, and prompt-injection/extraction patterns in `src/security/blocker.py`; wait for the A2A Judge verdict before launching `runner.run_async()`; drop the redundant `tools=[judge_tool]` round-trip from `judge_agent`, wrap untrusted input in `<user_input>...</user_input>`, return a closed 1-token enum (`ALLOW` | `BLOCKED` | `OFF_TOPIC`) parsed by a shared fail-closed helper (eliminating empty-output fail-open and `"My card was blocked"` echo collisions), and add bounded A2A HTTP timeouts in `src/a2a/client.py` plus local `mask_sensitive_data()` fallback when the A2A Masker is unreachable; align `ALLOWED_CHARS` vs. `_FINAL_PATTERN` (`()`) in `src/security/sanitizer.py`, and fix misleading step `runs` descriptions in `src/api/web.py`.
- **Defense-in-depth customer-support domain-scope, confidentiality, policy & `action-log` guardrails (`src/core/prompts.py`, `src/agents/judge_agent.py`, `src/core/memory.py`, `src/api/web.py`, `src/api/cli.py`):** Add `## Domain Scope` (including hybrid-turn partial fulfillment and no creative rewrites of order data), `## Confidentiality & Persona Lock`, `## Policy Boundaries` (no unauthorized refund/discount promises or legal/medical/competitor advice), and an untrusted-memory data rule to `SQL_PROMPT_INSTRUCTION`; extend `JUDGE_INSTRUCTION` with `BLOCKED` > `OFF_TOPIC` > `ALLOW` precedence and stateless fail-open on short follow-ups/metaphorical complaints; handle `"OFF_TOPIC"` in `src/api/web.py` (`stage="judge"`, `reason="off_topic"`) and `src/api/cli.py` by halting before `runner.run_async()`, skipping `_transcripts`/Mem0 recording, and returning a polite support redirect; wrap `search_memory` output as untrusted data; allowlist `action_type` + validate JSON `parameters` for `action-log` in `_enforce_tenant_tool_callback`; and add a dedicated 15-case customer-support boundary test suite in `tests/unit/test_security.py`.
- **100% seeded PII redaction without over-masking prose/order dates:** Extend `PERSON_NAME` and `STREET_ADDRESS` regexes in `src/security/masker.py` so single-letter surnames (`Hannah M`, `Charlie D`, `Evan G`, `George J`), additional street suffixes (`Pkwy`, `Path`, `Way`, `Pl`, `Cir`, `Ter`), numbered streets/units (`123 5th Ave`, `Apt 4B`, `Suite 200`), and optional trailing `, <City>` suffixes (guarded against common clause starters/stop-words) are masked cleanly; add salutation stop-words (`hi`, `hello`, `hey`, `dear`, `thanks`, `thank`, `welcome`) so greetings are not swallowed into `PERSON_NAME`; and narrow `DATE_OF_BIRTH` matching so bare order dates (e.g., `2026-10-15`) remain readable while actual DOB phrases are masked.
- **Session-bound memory tool, fail-closed tenant callback & core resilience:** Add a session-bound `make_memory_search_tool(user_id)` wrapper in `src/core/memory.py` (handling both `dict` and `list` Mem0 responses) so ADK tools never expose `user_id` to the model while keeping `search_memory(query, user_id)` for direct Python callers; harden `_enforce_tenant_tool_callback` in `src/api/web.py` to fail closed when session identity is missing and inject required tenant email args even if omitted by the LLM; log DB connection errors in `src/core/greet.py` (`authenticate_user`); and document `get_user_actions` in `auth-memory-telemetry`.
- **A2A single-role, CORS, memory-leak & protocol hardening:** Document `A2A_ONLY=judge|masker`, explicit `src/a2a/*.py` & `src/agents/*.py` paths, and `tasks/pushNotification/{set,get}` (keeping `AgentCapabilities.pushNotifications=False`) in `a2a-microservices`; add safe `PORT`/`HOST` fallback in `src/a2a/run_servers.py`; support a configurable advertised card host (`A2A_PUBLIC_HOST` / `RAILWAY_PRIVATE_DOMAIN` fallback) in `src/a2a/factories.py`; set `allow_credentials=False` on `CORSMiddleware` in `src/a2a/server.py`; delete ephemeral `judge_{uuid4()}` sessions in a `finally:` block in `src/agents/judge_agent.py`; bound `InMemoryTaskManager.tasks`/`task_messages` with FIFO eviction in `src/a2a/task_manager.py`; accept `id: int | str` in `src/a2a/types.py`; audit/clean dead `mask_agent` / `security_pipeline` references (updating `tests/integration/test_a2a.py` if removed); and align `tests/evals/test_config.json` with `SimpleEvaluator`.

### Modified Capabilities
- `security-guardrails`: Require live web/CLI channels to evaluate `SecurityBlocker` on raw input prior to sanitization, block bare `TRUNCATE TABLE` and `DELETE FROM`, enforce strict pre-agent Judge gating, enforce defense-in-depth customer-support domain scope (`OFF_TOPIC` Layer 2 Judge verdict with polite redirect + prompt scope), redact all seeded customer names/street suffixes/numbered streets/cities in `mask_sensitive_data` without swallowing greetings or bare order dates, align sanitizer whitelist/final regex and metadata, and align eval config with the local evaluator.
- `auth-memory-telemetry`: Require the ADK `search_memory` tool exposed to the model to bind the session `user_id` internally (supporting both dict and list Mem0 responses), enforce customer-support domain scope in `SQL_PROMPT_INSTRUCTION`, log database errors while failing closed in `authenticate_user`, and document `get_user_actions`.
- `a2a-microservices`: Require deterministic `BLOCKED` enforcement, `OFF_TOPIC` domain-scope classification for benign non-support requests, and ephemeral session cleanup in `call_judge_agent`, document single-role `A2A_ONLY=judge|masker` mode with safe port fallback, advertise routable discovery card URLs instead of `0.0.0.0`, accept `int | str` JSON-RPC IDs with bounded in-memory task storage and valid CORS (`allow_credentials=False`), and document `tasks/pushNotification/set` and `tasks/pushNotification/get`.

# Design

## Context

See `proposal.md` for motivation and drift citations. Currently:
- `src/api/web.py` and `src/api/cli.py` strip non-whitelisted characters via `sanitize_input()` before calling `evaluate_prompt()` and `_judge()`, defeating regex rules in `SecurityBlocker` for 17/61 malicious scenarios, while `src/security/blocker.py` lets bare `TRUNCATE TABLE` and `DELETE FROM` pass.
- `src/api/web.py` starts `runner.run_async()` concurrently with `_judge()` whenever `flagged_by_blocker` is false (tested by `test_parallel_judge_and_agent_cancels_agent_on_block`).
- `src/security/masker.py` regexes miss single-letter surnames (`Hannah M`), `Pkwy`/`Path`/numbered streets (`123 5th Ave`, `Apt 4B`), and trailing cities, while over-masking greetings (`"Hi Alice Jones"`) and bare order dates (`2026-10-15`).
- `src/core/memory.py` exports `search_memory(query, user_id)` directly to ADK `tools=[]` and assumes dict-only Mem0 responses; `src/api/web.py` `_enforce_tenant_tool_callback` skips when session identity is empty or an identity key is absent from `args`; `src/core/greet.py` swallows DB exceptions silently in `authenticate_user`.
- `src/a2a/run_servers.py` and `src/a2a/factories.py` hardcode `0.0.0.0` (including inside the discovery card `url`) and require `os.environ["PORT"]`; `src/a2a/server.py` combines `allow_origins=["*"]` with `allow_credentials=True`; `src/agents/judge_agent.py` never deletes per-call sessions; `src/a2a/task_manager.py` never bounds `self.tasks`/`self.task_messages`; `src/a2a/types.py` restricts JSON-RPC `id` to `int`.
- `src/agents/mask_agent.py` (`mask_agent` LlmAgent) and `src/agents/pipeline.py` (`security_pipeline` SequentialAgent, still imported by `tests/integration/test_a2a.py`) are unreferenced runtime leftovers.

## Goals / Non-Goals

**Goals:**
- Close the 17/61 live blocker bypass, block bare `TRUNCATE TABLE` / `DELETE FROM`, and eliminate speculative LLM/tool execution before Judge approval.
- Enforce defense-in-depth customer-support domain scope so benign off-topic requests (poems, jokes, general writing, trivia, coding) are politely declined across Explain, Quick, Voice, and CLI without false-blocking greetings or shopper queries.
- Achieve 100% redaction recall across all seeded shoppers and addresses in `mcp_toolbox/seed.sql` without swallowing greetings, order-status tokens, or order dates.
- Prevent the LLM tool schema from exposing a writable `user_id` argument for `search_memory`, fail closed in `_enforce_tenant_tool_callback`, handle list/dict Mem0 responses, and log DB auth errors.
- Make A2A single-role mode (`A2A_ONLY`) safe with missing `PORT` and routable discovery cards, fix invalid CORS, prevent unbounded Judge/task memory leaks, and accept `int | str` JSON-RPC IDs.

**Non-Goals:**
- Re-introducing Google Cloud DLP, Model Armor, or any external cloud security SDK.
- Modifying `src/core/telemetry.py` or `px.launch_app()` (owned and removed cleanly in Change `16-dependency-and-telemetry-upgrades`, executed before Change `13`).
- Adding signed HTTP/WebSocket session cookies/tokens for bare `user_id` endpoints (deferred to a dedicated future auth change so Change `13` does not break existing API/test contracts).
- Adding a separate standalone Layer 2b topical microservice (domain scope is enforced directly inside Layer 2 A2A Judge + `SQL_PROMPT_INSTRUCTION` with zero extra network hops).
- Fixing voice streaming/Quick-mode/Mem0-flush bugs (scoped to Change `14`).

## Decisions

1. **Raw-input unconditional blocker, bare destructive SQL/prompt-extraction, 0-tool single-token Judge & Masker fallback (`src/api/web.py`, `src/api/cli.py`, `src/security/blocker.py`, `src/agents/judge_agent.py`, `src/a2a/client.py`):**
   - Check `evaluate_prompt(raw_text)` (and `evaluate_prompt(clean)`) unconditionally in `text_pipeline()` (`src/api/web.py`) and `validate_input()` (`src/api/cli.py`). When `run_judge=False` (Quick mode or Judge toggle off), still block locally in `<1 ms` whenever `evaluate_prompt()` returns `"BLOCKED"` so malicious payloads never bypass Layer 1b in Quick mode.
   - Narrow bare `r"#"` (`src/security/blocker.py:50`) to `r"<!--\s*#"` so `"Status of order #5?"` and `"Apt #4B"` pass raw-input screening cleanly; add `r"\bTRUNCATE\s+TABLE\b"`, `r"\bDELETE\s+FROM\b"`, and focused prompt-injection/extraction patterns (`disregard/forget/override previous rules/instructions`, `repeat/reveal/print/show system prompt`, `DAN mode`, `developer mode`, `[SYSTEM]:`) while keeping `blocker.py` strictly free of brittle English off-topic wordlists.
   - In `src/agents/judge_agent.py`, short-circuit `call_judge_agent(query)` to return `"BLOCKED"` whenever `evaluate_prompt(query) == "BLOCKED"`, **remove `tools=[judge_tool]`** from `judge_agent` (eliminating a redundant Gemini Flash tool-call round-trip on every benign Explain turn), wrap untrusted text in `<user_input>...</user_input>`, return a closed 1-token enum (`ALLOW` | `BLOCKED` | `OFF_TOPIC`), read all text parts, and delete the ephemeral `judge_{uuid4()}` session in a `finally:` block.
   - Centralize Judge verdict parsing in a shared fail-closed helper used by both `web.py` and `cli.py` (accepting `ALLOW` / `BLOCKED` / `OFF_TOPIC` after stripping whitespace/punctuation, failing closed on empty/`None`/unparseable verdicts, and eliminating echo collisions like `"My card was blocked on order 5"`).
   - Add a bounded HTTP request timeout (`15 s`) on A2A client calls in `src/a2a/client.py`, and fall back to local `mask_sensitive_data(text)` in `web.py` (`_mask`) and `cli.py` (`_mask_response`) when the A2A Masker is unreachable instead of failing open to raw PII.
   - In `src/api/web.py`, await `_judge(...)` completely before creating the `runner.run_async()` task so blocked/off-topic turns never hit Gemini or MCP tools. Update `test_parallel_judge_and_agent_cancels_agent_on_block` in `tests/unit/test_demo_mode.py` to assert strict pre-agent gating.

2. **Sanitizer & Masker step consistency (`src/security/sanitizer.py`, `src/api/web.py`):**
   - Remove `()` from `_FINAL_PATTERN` so `ALLOWED_CHARS` and `_FINAL_PATTERN` accept the exact same characters and preserve `test_sanitizer_strips_characters_outside_the_whitelist`.
   - Change `runs="regex blocklist in src/security/sanitizer.py"` in `src/api/web.py` to `runs="length and character whitelist in src/security/sanitizer.py"`, and change the Masker step's `runs=f"ADK agent behind an A2A server at :{settings.mask_port}"` (`src/api/web.py` line 634) to `runs=f"local regex masker behind an A2A server at :{settings.mask_port}"`.

3. **Seeded PII regex expansion & false-positive guards (`src/security/masker.py`):**
   - Update `STREET_ADDRESS` to support numbered/ordinal street names (`(?:\d+(?:st|nd|rd|th)|[A-Z][a-z]+)`), expanded suffixes (`Street|St|Avenue|Ave|Road|Rd|Boulevard|Blvd|Lane|Ln|Drive|Dr|Court|Ct|Parkway|Pkwy|Path|Way|Place|Pl|Circle|Cir|Terrace|Ter|Trail|Trl`), optional unit/apartment suffixes (`(?:,?\s+(?:Apt|Apartment|Suite|Ste|Unit|#)\s*[A-Za-z0-9-]+)?`), and optional trailing `, <City>` (1–2 capitalized words) checked via a callback against `_NAME_STOP` + common clause starters (`"please"`, `"is"`, `"was"`, `"your"`, `"and"`, `"for"`, `"on"`, `"with"`, `"we"`, `"i"`, `"the"`, `"order"`, `"status"`, `"delivery"`, `"shipped"`, `"delivered"`, `"processing"`, `"cancelled"`, `"returned"`) so `"123 Market St, Springfield"`, `"200 Business Pkwy, Austin"`, and `"123 5th Ave, Apt 4B, Springfield"` redact completely while `"123 Market St, Please confirm"` does not over-mask `"Please confirm"`.
   - Update `PERSON_NAME` from `\b[A-Z][a-z]+(?:\s+[A-Z][a-z]+)+\b` to `\b[A-Z][a-z]+(?:\s+(?:[A-Z][a-z]+|[A-Z]\.?))+\b`, add salutation/greeting words (`"hi"`, `"hello"`, `"hey"`, `"dear"`, `"thanks"`, `"thank"`, `"welcome"`) to a leading-salutation guard / `_NAME_STOP` (splitting off a leading greeting word before masking the name so `"Hi Alice Jones!"` becomes `"Hi ***********!"` and `"Hi Hannah M!"` becomes `"Hi ********!"` rather than hiding `"Hi"`), and keep domain stop-words (`"option"`, `"grade"`, `"plan"`, `"tier"`, `"item"`, `"size"`, `"type"`, `"model"`, `"usb"`, `"gen"`) so prose and order statuses stay intact.
   - Narrow `DATE_OF_BIRTH` so bare ISO/US order dates (`"Order placed on 2026-10-15"`) are not redacted, while DOB-contextualized dates (e.g., `DOB`, `date of birth`, `born on`, `birthday` followed by `YYYY-MM-DD` or `MM/DD/YYYY`) are masked cleanly.

4. **Session-bound ADK `search_memory` wrapper, untrusted-memory framing, fail-closed tenant/`action-log` callback & core resilience (`src/core/memory.py`, `src/core/greet.py`, `src/api/web.py`, `src/api/cli.py`):**
   - Keep top-level `search_memory(query: str, user_id: str)` unchanged (preserving `tests/unit/test_core.py` `test_memory_search_does_not_take_a_second_identity`), handle both `dict` (`memories.get("results")`) and `list` return shapes from Mem0, and frame returned memory entries as untrusted data (`untrusted_note` / `<saved_preferences>` wrapper) so indirect prompt injections saved in Session 1 cannot execute as instructions in Session 2.
   - Add `make_memory_search_tool(user_id: str)` returning a function named `search_memory(query: str) -> dict[str, Any]` closed over `user_id`, and register `make_memory_search_tool(user_id)` in `web.py` and `cli.py` alongside keeping `_enforce_tenant_tool_callback` as defense-in-depth.
   - Harden `_enforce_tenant_tool_callback` (`src/api/web.py`) with a tool-to-identity-arg map (`{"get-order-status": "customer_email", "find-customer-orders": "email", "action-log": "user_email", "search_memory": "user_id"}`): if `_session_identity(tool_context)` is empty, fail closed by returning `{"error": "Missing authenticated session identity."}`; otherwise inject/overwrite the tool's required identity arg (plus any other `_IDENTITY_ARG_NAMES` present in `args`) with the session identity. For `action-log`, also enforce an explicit `action_type` allowlist (`UPDATE_ORDER_STATUS`, `RETURN_ITEM`, `UPDATE_DELIVERY_ADDRESS`, `UPDATE_PROFILE_DETAILS`, `CANCEL_ORDER`, `RETURN_ORDER`, `UPDATE_ADDRESS`, `UPDATE_PROFILE`) and validate JSON `parameters` so prompts cannot log fabricated `ISSUE_REFUND` / `GRANT_DISCOUNT` rows.
   - Log database exceptions in `src/core/greet.py` (`authenticate_user`) with `logger.warning(...)` before returning `None` so Neon/Postgres connection failures are diagnosable in logs.

5. **A2A single-role fallback, routable card URL, CORS, task eviction & JSON-RPC `id` (`src/a2a/`, `src/agents/`):**
   - In `serve_one(role)` (`src/a2a/run_servers.py`), read `host = _env_text("HOST", "0.0.0.0")` and `port = _env_port("PORT", _env_port("A2A_JUDGE_PORT", DEFAULT_JUDGE_PORT))` (or `A2A_MASK_PORT` for `masker`).
   - In `_card()` (`src/a2a/factories.py`), compute `advertised_host`: when `host == "0.0.0.0"`, check `A2A_PUBLIC_HOST`, then `RAILWAY_PRIVATE_DOMAIN`, then default to `"localhost"` so `/.well-known/agent.json` always advertises a routable URL while all URLs/hosts/ports remain env-configurable with localhost defaults. Keep `_CAPABILITIES.pushNotifications = False` and document `tasks/pushNotification/{set,get}` explicitly in `a2a-microservices/spec.md`.
   - In `src/a2a/server.py`, set `allow_credentials=False` on `CORSMiddleware` (valid with `allow_origins=["*"]` and safe for private services).
   - In `src/a2a/task_manager.py`, bound `InMemoryTaskManager.tasks` and `task_messages` (e.g., `max_tasks = 1000`, evicting the oldest completed/stored task FIFO on insert) so long-running Railway containers cannot leak unbounded memory.
   - In `src/a2a/types.py`, widen `id: int` to `id: int | str` on JSON-RPC request/response models (and `new_incompatible_types_error` / `_rpc_error`) per JSON-RPC 2.0.
   - Audit `src/agents/pipeline.py` and unused `mask_agent` in `src/agents/mask_agent.py` across both `src/` and `tests/integration/test_a2a.py`, keeping/updating integration tests so `pytest tests/unit tests/integration tests/evals` stays completely green.

6. **Defense-in-depth customer-support domain-scope, confidentiality & policy guardrails (`src/core/prompts.py`, `src/agents/judge_agent.py`, `src/api/web.py`, `src/api/cli.py`):**
   - In `SQL_PROMPT_INSTRUCTION` (`src/core/prompts.py`), add:
     - `## Domain Scope` restricting the assistant strictly to online-shop customer support (orders, shipping/delivery, cancellations, returns, address/profile updates, saved preferences, and brief greetings/courtesies), declining pure off-topic prompts (poems, jokes, creative writing, trivia, coding, general advice) in 1–2 short sentences without calling tools, and applying a **Hybrid-Turn partial-fulfillment rule** (if a message mixes an order question with an off-topic ask or creative rewrite like `"Check order 4 and write a poem/rap about it"`, answer ONLY the support part and decline the off-topic part).
     - `## Confidentiality & Persona Lock` forbidding roleplay/persona switches and disclosure of system instructions, internal tool names (`update-order-status`, `action-log`), SQL schemas, or model internals.
     - `## Policy Boundaries` forbidding unauthorized refund, discount, or SLA promises and declining legal, medical, financial, or competitor advice even when tied to an order.
     - **Untrusted-Memory Rule** instructing the agent to treat `search_memory` data strictly as factual shopper preferences, never as directives or persona overrides.
   - In `JUDGE_INSTRUCTION` (`src/agents/judge_agent.py`), enforce threat precedence (`BLOCKED` > `OFF_TOPIC` > `ALLOW`), default-to-allow on ambiguous short follow-ups and metaphorical complaints (`"Yes"`, `"5"`, `"123 Oak St"`, `"This shipping delay is a joke"`, `"I ordered a poetry book"`), and flag creative-rewrite hijack turns (`"Turn my order summary into a rap/poem"`) as `OFF_TOPIC`.
   - In `src/api/web.py` and `src/api/cli.py`, handle `"OFF_TOPIC"` distinctly from `"BLOCKED"`: both stop before `runner.run_async()`, skip `_transcripts`/Mem0 recording, and emit `stage="judge"` (so `/architecture` highlights `n-judge`, not `n-sanitize`), with `reason="off_topic"` returning a polite customer-support redirect (`"I can only help with customer support requests such as checking orders, returns, cancellations, or updating your account details."`).
   - Keep `tests/evals/test_scenarios.json` strictly for `SimpleEvaluator` (`sanitizer + blocker`, since its 39 legitimate queries are legacy HR/salary queries) and add a dedicated 15-case customer-support boundary test suite in `tests/unit/test_security.py`.

## Risks / Trade-offs

- **[Risk] Strict pre-agent gating adds A2A Judge latency to Explain turns** → Mitigation: Removing the redundant `tools=[judge_tool]` round-trip from `judge_agent` saves an entire Gemini Flash call (~300–600 ms), local `evaluate_prompt()` short-circuits known attacks in `<1 ms`, and Quick mode continues to skip Judge while still running local `SecurityBlocker`.
- **[Risk] Over-eager `OFF_TOPIC` classification could block brief greetings, short follow-ups, or metaphorical complaints (`"Hi"`, `"Yes"`, `"5"`, `"This shipping delay is a joke"`, `"My card was blocked on order 5"`)** → Mitigation: Closed 1-token enum output eliminates echo collisions, `JUDGE_INSTRUCTION` defaults to `ALLOW` on ambiguity/short follow-ups, and a dedicated 15-case customer-support boundary test suite verifies zero false positives.
- **[Risk] Single-letter surname matching in `PERSON_NAME` could over-mask legitimate prose like `"Option A"` or `"Grade B"`** → Mitigation: Expand `_NAME_STOP` with domain/common words (`"option"`, `"grade"`, `"plan"`, `"tier"`, `"item"`, `"size"`, `"type"`, `"model"`, `"usb"`, `"gen"`) and handle leading greetings cleanly so `"Hi Hannah M!"` redacts only `"Hannah M"`.
- **[Risk] Narrowing `DATE_OF_BIRTH` requires context keywords to distinguish DOBs from order dates** → Mitigation: Match `dob`, `date of birth`, `birth ?date`, `born`, and `birthday` before `YYYY-MM-DD`/`MM/DD/YYYY` (preserving existing `test_security.py` coverage while stopping order-date corruption).
- **[Risk] Existing unit and integration tests assert old behavior (`test_parallel_judge_and_agent_cancels_agent_on_block`, `tests/integration/test_a2a.py` `security_pipeline` import)** → Mitigation: Update affected assertions explicitly and run `tests/unit tests/integration tests/evals` in verification.

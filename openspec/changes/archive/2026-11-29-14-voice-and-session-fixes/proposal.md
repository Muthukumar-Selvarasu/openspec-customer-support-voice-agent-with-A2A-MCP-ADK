# Proposal

## Why

The 2026-11-19 and 2026-11-26 EGM drift audits revealed critical privacy, demo-mode, session-flush, telemetry, performance, and channel-parity defects across the voice cascade, web UI, and operator CLI:

1. **Unmasked voice replies & raw user text saved to Mem0/traces, broken mask/STT metrics, cross-line address splitting, and `STREAM_ENABLED` interlock contradiction (`src/voice/router.py`, `src/api/web.py`, `.env.example`):** In voice turns with `MASK=true`, `router.py` persists unmasked `display` instead of masked `shown` (and raw unsanitized user `text`) to `_transcripts`/Mem0; `web.py` skips the `security.a2a_mask` span and writes unmasked `final_text` to `voice.turn` (`output.value`); `mask_t0` is started *after* `await mask_text(text)` finishes (reporting `0.0` s and hardcoded `"ms": 1`); `mask_tok` is never populated in `cost`; `send_cost()` hardcodes `stt.measured = True` even when `stt_charge()` fell back to PCM-byte estimation; `_CLAUSE_END` splits on `,\n` which can break multi-line addresses across separate `mask_text()` calls; `mask_enabled()` is captured once at router mount time instead of read dynamically; and `STREAM_ENABLED` / `_config_warnings()` / `.env.example` still claim streaming is completely off under `MASK=true` instead of clarifying raw-unmasked vs. sentence-masked streaming.
2. **Quick mode broken after browser login/voice connect, inability to clear overrides, and `/api/chat` stream flag bug (`src/static/index.html`, `src/voice/ui.js`, `src/api/web.py`, `src/voice/router.py`):** `syncGuardrails()` on `cs:login` and `sendGuardrails()` on WebSocket open automatically push `{judge: true, mask: true}` into `_guardrails[user_id]` and `voice_ws`; neither `POST /api/guardrails` nor `/voice/ws` can clear overrides back to `None` when `null` is sent; `_flush_shopper()` and `/api/login` never clear stale `_guardrails[user_id]`; and `demo_pipeline_kwargs()` returns `stream: True` for Quick mode even when `stream_endpoint=False` (`POST /api/chat`).
3. **Tab-close Mem0 flush permanently suppressed after any Push-to-Talk turn (`src/voice/ui.js`, `src/static/index.html`):** `startVoice({ ptt: true })` sets `window.csVoiceOn = true` and never clears it when PTT goes idle, causing `shouldFlushOnPageHide()` to return `false` forever after the first voice turn.
4. **Voice client races, STT drain, `.vbtn.on` state, and UI observability gaps (`src/voice/ui.js`, `src/voice/stt.py`, `src/voice/tts.py`, `src/voice/router.py`):** `ui.js` silently drops `timing` and `cost` frames (`case "timing": case "cost": break;`), still injects a hidden `#hold` button + `toggleHold()` (the only element that ever toggled `.vbtn.on`), triggers a spurious 1 s tail capture when `#mic` is released before `startVoice()` resolves, and sends `commit: true` on non-PTT VAD silence; `LiveUtterance.flush()` allows up to `700 ms` empty drain instead of `250 ms`; `stt.transcribe()` and `tts.synthesize()` remain unused.
5. **Async event-loop stall, UI CSS defects, Web/CLI parity & unsynced endpoints (`src/api/web.py`, `src/api/cli.py`, `src/static/index.html`, `src/static/theme.css`):** `trace_url()` makes a blocking sync `urllib.request.urlopen(..., timeout=2)` call inside async `chat_stream` and `voice_ws` (stalling the event loop for up to 2 s when Phoenix is down); `POST /api/login` omits `model` expected by `index.html`; `index.html` lacks cross-tab `storage` sync for `cs-theme`, collides `.steps summary .pill` with `.pill:hover` lift, and nests `position: fixed` `.ds-aurora`/`.ds-grain` inside backdrop-filtered `.login`; `cli.py` ignores `MASK=false`, duplicates `greet_user()`, omits `thinking_budget=0`, maps repeated tool calls to the first call's args, lacks `finally:` DB close in `_print_known_shoppers()`, and runs a fake 1.2 s `[2/3] Loading current orders` sleep; `web.py` records raw `req.message` while `cli.py` records sanitized `clean`; and `POST /api/guardrails`, `#guardrailToggles`, `POST /api/session`, `POST /api/page-leave`, and voice WS `guardrails`/`mode` controls are missing from the main specs.

> **Review decisions to confirm before apply (Decisions #1 & #3):**
> - **Decision #1 (Voice `MASK=true` streaming):** Keeps fast **sentence-by-sentence masked streaming** (preserving existing test `test_demo_mode_explain_speaks_each_masked_sentence`), adds a zero-latency guard against splitting mid-address on `,\n`, updates `cascade-voice-engine` spec to allow incremental sentence masking before TTS, and fixes Mem0/trace redaction, timing, span, and cost accounting around it.
> - **Decision #3 (Voice `timing` & `cost` in UI):** Renders per-turn latency and USD cost in the `"What happened"` inspector (aligning with `docs/ENGAGEMENT.md` §7 and `docs/02-problem-metrics.md` §2.3) instead of discarding those frames.

## What Changes

- **Fix voice masking redaction, span, timing, cost, `,\n` guard, `off_topic` TTS continuity, Judge error fallthrough & interlock wording (`src/voice/router.py`, `src/api/web.py`, `.env.example`):** Save masked `shown` and sanitized user text (`clean`) to `_transcripts`/Mem0 and set `voice.turn` `output.value` to the masked reply; measure actual cumulative `await mask_text(text)` elapsed time (`timing["mask"]` and `"ms"`), emit a real `security.a2a_mask` span, populate `mask_tok` for `cost`, track `stt.measured` accurately (false when estimated from PCM bytes), round `timing` consistently to 3 decimal places, avoid splitting `,\n` mid-address in masked streaming while keeping fast `.!?…` and `:` splits, read `mask_enabled()` dynamically per turn, speak Change `13`'s polite `off_topic` redirect via TTS (with optional static PCM caching) instead of returning in dead silence, handle pipeline `error` events cleanly in `run_agent` instead of falling through into `speak("")` and wiping the UI error bubble, and keep `STREAM_ENABLED = AGENT_RESPONSE_STREAM and not MASK_ENABLED` (raw unmasked streaming) while aligning `_config_warnings()`, `.env.example`, and `cascade-voice-engine/spec.md` wording.
- **Fix Quick mode, guardrail override clearing & lifecycle (`src/static/index.html`, `src/voice/ui.js`, `src/api/web.py`, `src/voice/router.py`):** Only apply guardrail overrides when the user explicitly toggles `#toggleJudge`/`#toggleMask` (while still re-syncing an explicit user choice across `restoreShopper()` / `cs:login`); support clearing overrides via explicit `null` in `POST /api/guardrails` (using `req.model_fields_set`) and `/voice/ws` (`mode`/`guardrails` handlers); clear `_guardrails[user_id]` on `_flush_shopper()` and `/api/login`; and fix `demo_pipeline_kwargs()` to respect `stream_endpoint` (`"stream": stream_endpoint`) in Quick mode.
- **Fix PTT tab-close Mem0 flush & quick-click race (`src/voice/ui.js`):** Track active mic capture in `window.csVoiceOn` (setting it `true` while actively listening/capturing/tailing and `false` once PTT pauses idle) so tab close flushes transcripts to Mem0 after PTT turns while still protecting an actively open mic; abort cleanly in `onMicPressStart()` if the user released `#mic` before `startVoice()` resolved.
- **Fix voice client, `.vbtn.on` active PTT state, STT drain cap, UI metrics & CSS defects (`src/voice/ui.js`, `src/voice/stt.py`, `src/voice/tts.py`, `src/static/index.html`, `src/static/theme.css`):** Render `timing` and `cost` frames inside `"What happened"`; remove the hidden `#hold` button and `toggleHold()` while toggling `.vbtn.on` (coral) on `#mic` during active PTT capture and `.vbtn.live` (teal) when connected/ready; send `{"type":"utterance_end"}` (without `commit: true`) on non-PTT VAD silence; cap empty `LiveUtterance.flush()` drain strictly at `_FLUSH_DRAIN_SEC` (`250 ms`); remove unused `stt.transcribe()` and `tts.synthesize()`; add `window.addEventListener("storage", ...)` for `cs-theme` in `src/static/index.html`; fix `.steps summary .pill` hover collision; and move `.ds-aurora`/`.ds-grain` outside backdrop-filtered `.login`.
- **Eliminate blocking Phoenix lookup & fix Web/CLI parity (`src/api/web.py`, `src/api/cli.py`):** Offload `trace_url()`'s Phoenix project-id HTTP lookup off the asyncio event loop (with failure cooldown caching so unreachable Phoenix never stalls turns by 2 s); include `model: AGENT_MODEL` in `POST /api/login`; record sanitized `clean` user text in `web.py` and `router.py` `_transcripts` to match `cli.py`; in `cli.py`, honor `mask_enabled()` (`MASK=false`), call `greet_user()`, add `thinking_budget=0` to `LlmAgent`, match each tool response FIFO to its queued tool call args, close DB connections in a `finally:` block in `_print_known_shoppers()`, and remove the fake 1.2 s `[2/3] Loading current orders` sleep.
- **Sync specs:** Update `cascade-voice-engine` and `web-and-cli-channels` specs for sentence-level masked voice streaming (with `,\n` guard and accurate `stt.measured`), WS `guardrails`/`mode` controls + override clearing, `stt_charge()`, `POST /api/guardrails`, `#guardrailToggles`, `POST /api/session`, `POST /api/page-leave`, non-blocking `trace_url()`, cross-tab theme sync, and `"What happened"` latency/cost display.

## Capabilities

### New Capabilities

### Modified Capabilities
- `cascade-voice-engine`: Permit sentence-by-sentence masked TTS streaming in Explain voice turns (with `,\n` address-split guard) while requiring masked text in Mem0/traces, real `security.a2a_mask` span/timing/cost reporting, accurate `stt.measured`, dynamic `MASK` checks, strict `250 ms` empty flush drain, no `#hold` button, `#mic` quick-click guard, non-PTT VAD `commit: false`, `"What happened"` latency/cost display, WS `guardrails` control, and `stt_charge()`.
- `web-and-cli-channels`: Ensure Quick mode skips Judge/Masker after normal login and voice connect unless explicitly overridden, allow tab-close Mem0 flush after idle PTT turns, keep Phoenix trace lookup non-blocking in async handlers, document `POST /api/guardrails`, `POST /api/session`, `POST /api/page-leave`, and `POST /api/login` `model` field, add symmetric cross-tab `cs-theme` sync and fix `.pill`/`.ds-aurora` CSS in `index.html`, and align CLI `MASK`, greeting, `thinking_budget`, sanitized transcripts, DB cleanup, loader, and tool-arg tracing with web.
